# 06 · 已知问题与开发坑（历史教训，改代码前先看）

> 以下每一条都是真实踩过的坑，对应修复已合入当前代码。
> **新问题出现时，先对照本表**，很多"玄学"都能在这里找到答案。

## 1. 环境/工具类

- **npm 安装失败（沙箱）**：本机用户缓存目录不可写。
  解决：`npm install ws --cache "F:\03 智能学习\04 Codex\Work 1\.npm-cache" --no-audit --no-fund`。
  以后装新包都加 `--cache .npm-cache`。
- **Node 子进程 spawn EPERM（沙箱）**：不能用 `stdio:'pipe'` 捕获子进程输出。
  test-net.js 已用 `stdio:'ignore'` + HTTP 轮询就绪。别改回 pipe。
- **PowerShell 里内联 node -e 中文/引号转义**：复杂脚本写成 .js 文件再跑，别硬拼命令行。

## 2. 游戏逻辑类

- **固定卡位重构曾打断一堆测试**：plantCard 曾推第 5 张卡进 board。
  规则：board 恒 4 槽；`refillBoard` 只填 null 槽；测试 plantCard 填 null 槽或替换槽 0 并把旧卡推回牌堆。
- **所有遍历 board 的地方都要跳过 null**（ai.js 多处、game.js 的 findCardInBoard/hasAnyLegalAction）——
  漏一处就是 `Cannot read properties of null`。
- **归还阶段（phase='discard'）只有 ui.js / server.js 设置**：单机 openDiscardModal 设、
  联机 handleAction 在 needDiscard 时设；game.js 只检查。
  **归还 1 枚后 ≤10 枚会立即 completeTurn 结束回合**（不是等 finishDiscard）——
  测试撤销归还时，必须保证触发时 >11 枚（如 12），否则还 1 枚就结束、没机会撤销。
- **多贵族选择**：buyCard 返回 `res.nobles.length > 1` 时前端 openNobleModal；
  chooseNoble 后还要继续检查归还/结束回合（单机 afterHumanAction / 联机 handleAction 流程）。
- **死局救济顺序**：联机 handleAction 在阶段校验前检查 hasAnyLegalAction 并自动救济；
  单机是弹窗让玩家点「继续」。两者行为一致（归还 1 枚最多筹码 + 结束回合）。
- **撤销快照**：takeSnapshot 只在轮到**真人**时保存（AI 回合不存）；
  undoLastTurn 弹 2 个快照恢复。联机无此功能。

## 3. UI 类

- **渲染顺序**：`render()` 里 renderPlayers 必须在 renderSelection 之前
  （sel-list 由 renderBank/renderPlayers 生成）。曾被 vm 桩掩盖后真实浏览器崩溃。
- **弹窗 z-index**：modal-mask 是 600（曾被主菜单 500 盖住 → 弹窗打不开）。
- **页面高度**：`.app { height: calc(100vh - 20px) }` + 内部 min-height:0——
  曾用 min-height 布局导致日志越长页面越长（V1.6 需求，勿回退）。
- **移动端**：≤1180px 单列布局时 `.info-panel { height:260px }`；≤700px 简化。
- **updateBankSelection**：选宝石只切 class 不重建宝石池（性能 + 动画）。

## 4. 联机类

- **先手随机**：createGame 默认先手随机。测试/UI 必须处理「开局可能轮到任意座位」
  （单机 startGame 后 `if (isAITurn()) aiTurn()` 已处理；测试用 waitTurn 循环等待）。
- **startGame 时掉线的座位**：必须标 `isAI: !s.connected`，否则真人座位无人行动导致死局。
- **test-net 竞态史**（已全部修复，别重蹈）：
  1. `wrap.wait` 只查 waiters[0] → 并发等待超时 → 改 findIndex；
  2. `autoPlay` 启动时 `curState` 未初始化 → TypeError 被 catch 吞掉、b 永不行动 → 先消费开局广播再启动；
  3. `settleAfterAction` 静默吞掉归还阶段 → 观察归还的测试必须 `manualDiscard:true`；
  4. 公共区枯竭（AI 囤宝石）→ humanTake 需回退链（盲抽→买卡）。
- **归还撤销（n=-1）**：服务器 returnTokens 支持负 count；前端乐观更新 returning 标记，
  服务器广播会校正。公共区不足时会被拒（极少见）。
- **房间码**：从 1000 递增、4 位数字、可被枚举（无鉴权）。适合朋友间玩，不适合公开陌生人局。

## 5. 部署类

- **Render 404 排查**：看日志三行 `[static] 根目录 / index.html 存在 / 文件清单`。
  `index.html 存在:false` = 部署包缺文件（查 GitHub 仓库与 .dockerignore）；
  完全没有 `[static]` 日志 = 服务没起来（看构建报错）。
- **静态根目录回退**：server.js 现在优先 `__dirname`，无 index.html 时回退 `process.cwd()`。
- **目录穿越**：路径用 `normalize(join(ROOT, url))` + 前缀检查（曾用 resolve+startsWith 有前缀漏洞）。
- **免费实例休眠**：Render 免费档闲置后首次访问慢几秒（唤醒），正常现象。
- **Vercel 对 WebSocket 支持有限**：长期稳定优先 Render/Railway。
