## 1. 项目是什么

纯 **HTML + CSS + 原生 JavaScript** 实现的《璀璨宝石》（Splendor）桌游网页版，
位于 `F:\03 智能学习\04 Codex\Work 1`（下称「项目根目录」）。

- **单机模式**：双击 `index.html` 即可玩（玩家 vs 1~3 个电脑 AI）
- **联机模式**：`node server.js` 启动服务器，2~4 名真人通过浏览器联机
  （服务器权威 + WebSocket，人数不足由 AI 补位）
- **AI 六档难度**：1 新手 ~ 6 专家（L6 为进化策略训练的权重）
- **当前版本**：V1.7（圆桌桌游化 UI + 联机对战），全部测试通过，可公网部署

## 3. 接手后第一件事：验证环境

在项目根目录执行（需要 Node.js ≥ 14；`ws` 已安装）：

```bash
node test.js            # 核心逻辑（报告 524 断言全过）
node ui-smoke.js        # 界面冒烟（62 断言）
node ui-strict-check.js # 严格 DOM 桩
node net-ui-check.js    # 联机界面路径（22 断言）
node test-net.js        # 联机协议集成（约 32 断言，自动起服务器，需 20~40 秒）
```

全部通过 = 环境与代码健康。若 `test-net.js` 偶发失败，先重跑一次
（见 06-已知问题与开发坑.md 的「test-net 竞态」一节，已知非代码缺陷的抖动已基本消除）。

## 4. 必须遵守的工作原则（用户明确要求过）

1. **单机模式永远不能坏**：双击 `index.html` 必须可玩。任何改动后跑 5 套测试。
2. **不安装非必要依赖**：目前唯一外部依赖是 `ws`（Node 联机服务器用）。
   新增 npm 包前先说明理由。浏览器端保持纯原生 JS。
3. **AI 难度 1~6，第 6 档必须是专家**：L6 权重来自 `ai_expert_weights.js`，
   按人数分组（2/3/4 人局），改动须重新训练（见 04-AI系统.md）。
4. **中文交流**：代码注释、提交说明、给用户的回复用中文。
5. **大改动先讲原因再动手**：用户习惯先听「为什么」，再改（例如布局类改动）。
6. **不要因为普通开发问题停下问用户**：能自查就自查（跑测试、读代码、查文档）。

## 5. 项目文件速览（详细见 02-架构与代码地图.md）

| 文件 | 一句话职责 |
| --- | --- |
| `index.html` | 页面结构（主菜单 / 联机大厅 / 圆桌场景 / 弹窗） |
| `style.css` | 全部样式（深色桌游风、响应式、联机样式） |
| `data.js` | 官方牌库（90 卡 + 10 贵族）+ 宝石定义 + 插画 emoji |
| `game.js` | **核心规则引擎**（纯逻辑、无 DOM、浏览器/Node 双兼容） |
| `aiConfig.js` | 六档 AI 参数表 + AI_DEBUG + 专家权重按人数加载 |
| `ai_expert_weights.js` | L6 训练权重（训练产物，勿手改；注释乱码不影响运行） |
| `ai.js` | AI 决策引擎（合法行动生成 / 评分 / 目标规划 / 对手分析） |
| `net-client.js` | 联机客户端（浏览器端 WebSocket，协议见文件头注释） |
| `ui.js` | 界面层（渲染 / 事件 / 弹窗 / 单机与联机双模式） |
| `server.js` | 联机服务器（静态托管 + WebSocket 房间，服务器权威） |
| `training/` | 训练脚本（train_expert.js 进化训练 / simulate_games.js 对阵统计） |
| `test*.js` | 5 套自动化测试（见 05） |
| `splendor_base_data.js` | 官方卡牌原始数据（核对来源，非运行时依赖） |
