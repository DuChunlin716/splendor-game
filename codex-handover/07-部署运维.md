# 07 · 部署运维

## 1. 本地 / 局域网

```bash
node server.js
# 输出示例：
#   💎 璀璨宝石服务器已启动
#   本地访问:  http://localhost:3000
#   局域网访问: http://192.168.x.x:3000
```

- 端口：`PORT=8080 node server.js`。
- 单机（无需服务器）：直接双击 `index.html`。

## 2. 公网部署（三平台，配置均已就绪）

项目根目录自带：`Dockerfile`、`render.yaml`（Render Blueprint）、
`railway.toml`（Railway）、`vercel.json`（Vercel）、`.dockerignore`、`.gitignore`。

| 平台 | 步骤 | 备注 |
| --- | --- | --- |
| Render（推荐） | 推 GitHub → render.com → New → Blueprint → 选仓库 → Deploy | 自动读 render.yaml；免费档休眠唤醒慢 |
| Railway | 推 GitHub → New Project → Deploy from GitHub repo | 自动读 railway.toml |
| Vercel | 推 GitHub → New Project → Framework 选 Other | WebSocket 支持有限，备选 |
| 自建/国内云 | 有 Docker：`docker build -t splendor . && docker run -p 3000:3000 splendor`；无 Docker：`node server.js` | 国内玩家多时延迟最低 |

通用流程：push → 平台连仓库 → 等 1~5 分钟 → 拿到 `https://xxx...` 网址 → 分享给朋友。
平台自动 HTTPS，前端自动用 `wss://`。

## 3. 部署后 Not Found 排查（用户刚踩过，重点）

1. 看平台日志（Render：顶部 Logs）启动输出三行：
   ```
   [static] 根目录: /app
   [static] index.html 存在: true
   [static] 文件清单: index.html, style.css, data.js, ...
   ```
2. 判定：
   - `index.html 存在: true` → 服务正常，刷新/等唤醒；
   - `index.html 存在: false` 或清单缺文件 → 部署包缺文件：
     检查 GitHub 仓库是否完整（尤其 index.html、style.css、data.js、game.js、
     aiConfig.js、ai_expert_weights.js、ai.js、net-client.js、ui.js），
     检查 `.dockerignore` 是否误排除（不应排除这些）；
   - 完全没有 `[static]` 日志 → 服务没启动，看构建/启动报错（如依赖安装失败）。
3. 运行时 404 会打印 `[static] 404 请求 -> 路径 (错误码)`，把该行发排查。

## 4. 运维要点

- **重启/重部署不影响数据**：房间状态在内存，重启后房间码失效（正常）。
- **免费额度**：Render free 512MB 内存足够；实例休眠后自动唤醒。
- **日志**：console.log/console.error 直接进平台日志（server.js 已打印静态诊断）。
- **安全**：无鉴权、无速率限制（朋友间使用场景）。若公开运营需加：连接数限制、
  房间码复杂度、action 频率限制（见路线图任务 F）。
- **更新流程**：改代码 → 本地 npm test 全过 → push → 平台自动重新部署。

## 5. 目录内文件核对（部署相关）

| 文件 | 作用 |
| --- | --- |
| Dockerfile | node:20-alpine，npm install（含 package-lock 锁定版本），EXPOSE 3000 |
| render.yaml | Blueprint：docker runtime + healthCheckPath:/ + PORT=3000 |
| railway.toml | Nixpacks + startCommand + healthcheckPath:/ |
| vercel.json | Node 服务型路由（备选） |
| .dockerignore | 排除 node_modules/.npm-cache/training/测试脚本/*.md 等（**勿排除运行时文件**） |
| .gitignore | 排除 node_modules/.npm-cache 等 |
