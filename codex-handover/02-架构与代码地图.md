# 02 · 架构与代码地图

## 1. 分层架构（核心设计：逻辑与 UI 完全分离）

```
data.js（静态数据）
   └─> game.js（规则引擎，纯函数式操作 gameState，无 DOM）
          └─> ai.js（AI 决策，只读 gameState + 调用 game.js 的合法性判断）
                 └─> ui.js（浏览器界面：渲染 gameState + 翻译点击为 game.js 调用）
                 └─> server.js（联机：跑 gameState，执行客户端指令，广播快照）
                        └─> net-client.js（浏览器端 WS 客户端，ui.js 使用）
```

- `game.js` / `ai.js` / `aiConfig.js` 都是 UMD 工厂（浏览器 `window.SplendorGame` 等 + Node `require`），
  Node 测试与浏览器共用同一份代码。
- **改规则只改 game.js；改 AI 只改 ai.js/aiConfig.js；改界面只改 ui.js/style.css/index.html。**

## 2. gameState 完整字段（改代码前必读）

```js
{
  players: [{
    name, isAI, aiLevel,            // 玩家信息（aiLevel 对真人也赋值，联机托管时被 AI 使用）
    aiWeights, aiAccuracy,          // AI 参数（createGame 时由 aiConfig 注入）
    tokens: {white,blue,green,red,black,gold},
    permanents: {white,...,gold:0}, // 永久宝石（折扣）
    cards: [card],                  // 已购发展卡
    reserved: [card],               // 预留卡（含盲抽）
    nobles: [noble],
    score, turnCount,               // turnCount 用于终局轮次判定
    lastAction: {...}               // 结构化「上回合行动」（见 §4）
  }],
  currentPlayer,                    // 当前行动玩家索引
  phase: 'action'|'discard'|'gameover',
  bank: {white,...gold},            // 公共宝石池
  decks: {1:[...],2:[...],3:[...]}, // 牌堆
  board: {1:[4槽],2:[4槽],3:[4槽]}, // 公开卡（固定 4 槽，空位为 null，见 §3）
  nobles: [noble],                  // 桌面贵族
  pendingNobles: [noble],           // 待选贵族（多贵族择一）
  turn, endTriggerTurn,             // 回合数 / 15 分触发回合（null=未触发）
  gameOver, winner,                 // winner 为 null 表示平局
  log: [{turn, text}],
  selection: [],                    // 前端本地选宝石状态（服务器快照中无意义，前端自行维护）
  aiLevel, aiGoal,                  // 局级 AI 难度 / 当前 AI 目标卡
  undoLeft, snapshots,              // 单机撤销（联机无意义）
  rng                               // 随机函数（JSON 序列化后丢失，前端不需要）
}
```

**卡牌 card 结构**：`{ id, tier, bonus, points, cost:{white..black}, art }`（art 为 emoji）。

## 3. 关键机制（改这些地方要特别小心）

### 3.1 固定卡位补牌（V1.6 核心需求，曾引发多次回归）
- `board[tier]` **恒为长度 4**：买/明牌预留后 `board[tier][idx] = null`，
  再由 `refillBoard` 找第一个 null 槽原位补新牌；牌堆耗尽则槽位保持 null。
- **所有遍历 board 的代码必须跳过 null**（`if (c)` / `if (card)`），
  包括：`ai.js` 的 legalActions / pickBuy / targetNeed / colorDemand / findCardFor，
  `game.js` 的 findCardInBoard / hasAnyLegalAction / checkInvariants。
- 新增任何读 board 的代码，第一行先处理 null。

### 3.2 阶段机（phase）
- `phase='action'`：正常回合。`completeTurn` 推进下一位（取模轮转）。
- `phase='discard'`：筹码 >10 的归还阶段。**只有 ui.js（单机）和 server.js（联机）设置该值**，
  game.js 只检查（needDiscard）。归还完毕 `finishDiscard` → `completeTurn`。
- `phase='gameover'`：终局。`finishGame` 结算（分数 → 卡少者胜 → 平局）。
- 终局规则：有人 ≥15 分记录 `endTriggerTurn`，所有玩家 `turnCount` 都 ≥ 该值后才结算。

### 3.3 撤销上一回合（单机）
- `takeSnapshot` 在轮到真人时保存快照；`undoLastTurn` 弹出 2 个快照恢复，
  `undoLeft` 每局 3 次。联机模式禁用（服务器无此功能，ui.js 隐藏按钮）。

### 3.4 死局自动救济
- `hasAnyLegalAction` 检查无合法行动时：单机弹窗「继续」→ `humanRelief`；
  联机由服务器 `autoRelief` 自动处理（归还 1 枚最多筹码并 completeTurn）。

## 4. lastAction 结构化格式（UI 与联机共享，盲抽防泄露）

```js
// 拿宝石
{ type:'takeTokens', tokens:{white:1, blue:1, green:1} }
// 购买
{ type:'buyCard', card:{id,tier,bonus,points,cost}, gainedNoble:true/false }
// 明牌预留
{ type:'reserveCard', card:{...}, gainedGold:true/false }
// 盲抽预留（关键：不携带 card，防止泄露隐藏信息）
{ type:'reserveCard', hidden:true, level:1|2|3, gainedGold:true/false }
```

由 `game.js` 的 takeTokens / buyCard / reserveCard / grantNoble 写入。
UI 渲染在 `ui.js` 的 `lastActionHtml`；**盲抽必须只显示层级+黄金**（用户明确要求）。

## 5. 单机 / 联机双模式分叉（ui.js）

- 全局：`netMode`（是否联机）、`mySeat`（我的座位，单机恒 0，联机由服务器广播）。
- `humanIdx()` 返回 `mySeat`；所有「玩家操作」判断用 `isHumanTurn()`。
- 联机时操作函数（confirmTake / buyFromModal / reserveFromModal / blindReserve /
  chooseNobleModal / returnOne / undoReturn / confirmDiscard / restart）改为
  **发送 WS 指令**，不直接改本地状态；服务器广播后由 `onNetState` 驱动渲染。
- 弹窗由状态驱动：归还弹窗 / 贵族弹窗在 `onNetState` 中按 phase/pendingNobles 自动开关
  （有 `discardOpen` / `nobleOpen` 防重复标志）。
- 座位渲染：联机下 `renderPlayers` 把「我」放主座位，其他玩家按索引顺序填 AI 座位，
  真人标记「👤 真人」，AI 显示难度。

## 6. 渲染顺序与性能注意

- `render()` 顺序：renderHeader → renderStatus → renderNobles → renderTiers →
  renderBank → **renderPlayers → renderSelection**（renderSelection 依赖 sel-list 已渲染）。
- 页面高度链：`.app { height: calc(100vh - 20px); min-height:480px }`，
  `.info-panel/.log-box/.log { min-height:0; overflow:auto }`——**不要改回 min-height 布局**，
  否则日志会让页面无限变长（V1.6 曾修过）。
- 选宝石即时反馈用 `updateBankSelection`（不重建宝石池，只切 class + 弹跳动画）。

## 7. 事件绑定（ui.js bind()）

- `#table-scene` 事件委托：btn-confirm-take / btn-clear-take + `.card[data-card-id]`。
- 顶栏：btn-restart / btn-rules / btn-sound / btn-undo。
- 主菜单：btn-menu-start / btn-menu-net / 难度与人数拉条（diff-slider / players-slider 1-6 / 2-4）。
- 联机大厅：net-name / net-players-slider / net-diff-slider / 创建/加入/开始/离开按钮。

## 8. 构建与运行

- 无构建步骤。浏览器直接加载：data.js → game.js → aiConfig.js → ai_expert_weights.js →
  ai.js → net-client.js → ui.js（顺序不可乱，index.html 已排好）。
- 服务器：`node server.js`（静态托管同目录所有文件 + WS）。
- `璀璨宝石.html` 是 `index.html` 的副本，**改 index.html 后必须同步复制**。
